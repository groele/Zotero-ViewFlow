# Zotero ViewFlow 13.1.5

Release date: 2026-11-06  
Part of Zotero Flow series.

## Major Highlights & Changes (工程架构治理与标准化对齐)

### 1. 提炼全系标配架构合规守卫 (§5.9 Architecture Guard & Baseline)
- **从测试内嵌断言提炼为独立守卫**：将原分散在测试中的行长约束提取为全系标配的 `scripts/architecture-guard.mjs`，包含 14 项全方位静态合规守卫；
- **确立零欠账基线 (`debtCleared: true`)**：正式出具 `scripts/architecture-baseline.json`，冻结策略采用 `freeze-and-shrink`，声明 `debtCleared: true` 与空的超长列表 `oversized: {}`；
- **11 个源码文件 100% 达成 360 行基准**：全仓 `src/` 下全部 11 个 TypeScript 模块严格约束在 360 行以下（最大模块 `src/index.ts` 仅 354 行），正式跻身全系标准第一梯队；
- **全生命周期构建守卫守候**：在 `package.json` 中配置 `guard` 与 `check:architecture` 脚本，在 `npm run build` 与 `npm test` 流水线中强制前置执行架构守卫。

### 2. 多维度合规与治理规则对齐
- **五语 Fluent 对称性治理**：静态验证 `en-US`、`zh-CN`、`en-GB`、`es-ES`、`fr-FR` 五大本地化语言文件具有完全对称的 50 个键值且无任何重复键；
- **设置面板零硬编码文案**：`prefs.xhtml` 100% 由 Fluent `data-l10n-id` 驱动，首张卡片唯一默认展开（`open="open"`），严格遵守 §4.2 的 16px/24px/40px 容器排版对齐网格；
- **运行时环境安全保证**：静态封禁 `@ts-nocheck`、`Components.classes`、遗留 `Cu.import` 及 `CheckboxStateChange` 等废弃旧 Gecko API，全面拥抱 Zotero 10 ~ 12 现代架构。
