# Zotero ViewFlow 16.0.0

Zotero ViewFlow 正式发布 **16.0.0** 大版本，标志着全系统一大版本（Zotero Flow Unified Major Release 16.0.0）协同确立。

## 🌟 核心升级与特性

1. **统一全系大版本号**：跃升至 16.0.0，与 Zotero Flow 家族其余六大插件保持完全一致的版本号与协同发布节拍；
2. **纯净现代化架构底座**：全仓 11 个 TypeScript 模块严格恪守 360 行上限约束（0 债务），静态类型检查 100% 通过；
3. **架构守卫体系化**：集成独立 `scripts/architecture-guard.mjs`，构建前置静态断言；
4. **双向 Fluent 本地化中英双语严格对称**：设置面板 100% Fluent `data-l10n-id` 驱动，零硬编码；
5. **完整自动化测试验证**：语法、架构与全部单元测试 100% 通过。
