# Zotero ViewFlow 12.5.2

Released: 2026-10-21

Fix the build/test handoff that caused a clean checkout to fail release checks when the current installer was absent from `dist`.

## Fixed

- Build a temporary XPI during release tests and remove it afterward; no pre-existing versioned installer is required.
- Retain strict installer SHA-256 and source-resource validation. Verify existing release artifacts read-only with `test.ps1 -PackagePath <XPI-path>` or `VIEWFLOW_XPI_PATH`.
- Keep normal builds and tests from rewriting the published update feed. Release preparation must explicitly use `build.ps1 -UpdateFeed`.
- Ignore new local installer outputs while retaining historical tracked installers.
- Align manifests, settings labels, current download links and update metadata with 12.5.2. Correct the settings-pane download URL to the current `v12.5.2` tag convention.

## Installation

Install `Zotero-ViewFlow-12.5.2.xpi` through Zotero's add-on manager. Do not install the GitHub source archive. Existing preference keys and preview/copy behavior are unchanged. Declared Zotero compatibility remains 8.0 through 11.0.*.

## Verification

- All 27 tests passed, with zero failures or skips, including temporary-build and strict checksum verification.
- JavaScript syntax and XPI resource checks passed. The attached verification report and SHA256SUMS describe the exact installer.
- An installer with a changed overall checksum was rejected. Explicit update-feed writing was validated in an isolated fixture.
- Native Zotero desktop installation was not rerun; this tooling release does not establish new host compatibility coverage.
