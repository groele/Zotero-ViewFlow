# Zotero ViewFlow 12.6.0

Release date: 2026-10-27. This backward-compatible minor release incorporates the earlier local 12.5.4 lifecycle fix and the 12.6.0 preview improvements. Add-on identity, saved settings and compatibility declarations are preserved.

## Changes

- Retry a failed preview from its error message. Distinguish missing installed styles, unsupported Quick Copy formats and incomplete formatting results, with localized recovery guidance.
- Keep a missing saved style visible in the settings menu rather than silently presenting the Quick Copy default. A dedicated ViewFlow style remains usable when Quick Copy settings are invalid, while preserving the existing HTML-source copy option when they are valid.
- Wait for Zotero's style initialization before formatting. Discard completion and failure from an older item or closed section.
- Recheck the actual library selection and deleted state before copying, so a stale preview cannot copy the previous selection.
- Apply font and spacing changes immediately without regenerating CSL or discarding the shared cache and copy animation. User spacing now overrides inline CSL line-height and also applies to in-text citations.
- Announce successful copying through a localized status region while preserving the original copy icon, keyboard activation and feedback animation.
- Localize the settings version information and link downloads to the immutable release installer. Scope preference CSS to ViewFlow and retain the four single-level groups and 14px controls.
