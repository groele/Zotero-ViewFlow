# Zotero ViewFlow 17.0.0

**发布日期**：2026-11-13
**适用版本**：Zotero `10.0` - `12.*`

Zotero ViewFlow 正式发布 **17.0.0** 大版本，与 Zotero Flow 全家桶协同迈入 `v17.0.0` 统一大版本周期。

## 🌟 核心升级与验证

1. **统一全系大版本号 (`v17.0.0`)**：同步更新 `manifest.json`、`package.json`、`package-lock.json`、`docs/brand/product.json`、`scripts/architecture-baseline.json`、`prefs.xhtml`、中英文 `README` 及 `update.json` 更新源。
2. **源码健康度与合规审计**：全仓 `src/` 17 个 TypeScript 模块均严格满足 `<= 360` 行上限（最大 359 行，零债务），无 `@ts-ignore` / `@ts-nocheck`，无裸露 `console.log`，事件监听均基于 `AbortController` 或显式清理。
3. **确定性打包与自动校验**：`tsc --noEmit` 静态类型检查、14 项架构守卫 (`scripts/architecture-guard.mjs`)、脚本语法检查 (`test:syntax`)、95 项单元测试 (`test:unit`) 与确定性 XPI/SHA-512 更新源生成全链路 100% 通过。
4. **验证边界说明**：本版本已完成完整自动化静态检查、打包校验与单元测试；未在本轮运行桌面端实机 Zotero UI 联调。
